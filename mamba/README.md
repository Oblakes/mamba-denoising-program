# mamba-denoising-program

一个基于 Qt Widgets 的 WAV 音频带噪声合成与去噪程序。

## 功能

- 选择一段原始 WAV 音频。
- 选择一段或多段噪声 WAV 音频。
- 调整噪声叠加强度或去噪强度。
- 生成带噪声音频，并保存为 WAV 文件。
- 使用参考噪声对带噪声音频执行自适应去噪，并保存去噪结果。
- 原始音频、噪声音频、混合输出和去噪输出都可以在软件中直接播放，也可以停止播放。
- 播放 WAV 时实时显示频谱柱状图，展示当前音频片段的频率分布。
- 输出 16-bit PCM WAV 文件。

## 输入要求

- 支持 PCM 8/16/24/32 位 WAV，以及 32 位浮点 WAV。
- 噪声音频可以和原始音频使用不同采样率，程序会自动重采样到原始音频的采样率。
- 噪声音频可以和原始音频使用不同声道数，程序会自动转换到原始音频的声道数。
- 如果噪声音频比原始音频短，会循环使用噪声音频直到覆盖完整原始音频。

## 算法说明

合成带噪声音频时，程序逐采样叠加原始音频和噪声音频：

```text
输出 = 原始音频 * 原始增益 + 噪声叠加强度 * (噪声 1 + 噪声 2 + ...)
```

去噪时，程序使用 NLMS（Normalized Least Mean Squares，归一化最小均方）自适应滤波做参考噪声抵消。选择的噪声音频作为参考输入，程序按声道维护一组自适应 FIR 滤波器，估计混合音频中的噪声分量：

```text
参考噪声 x(n) -> NLMS 自适应滤波器 -> 估计噪声 y(n)
输出 e(n) = 带噪音频 d(n) - 去噪强度 * y(n)
```

滤波器系数会根据误差自动更新：

```text
w(n+1) = w(n) + mu * e(n) * x(n) / (||x(n)||^2 + epsilon)
```


处理结果会限制在 [-1.0, 1.0] 范围内，避免保存 16-bit PCM 时溢出。
